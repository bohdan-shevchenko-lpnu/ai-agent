## Опис проєкту

Мета проєкту — створити спеціалізованого AI-агента для автоматизації розробки програмного забезпечення та налаштування CI/CD.

Агент повинен автоматизувати створення кросплатформного проєкту Hello World мовою JavaScript, налаштування npm scripts, написання та запуск модульних тестів за допомогою Jest, а також створення GitHub Actions workflow для автоматичної перевірки проєкту в операційних системах Windows, Linux і macOS.

Для організації роботи агента використовуються спеціалізовані інструкції (skills), команди (prompts/commands) та orchestrator, який координує етапи виконання, контролює помилки й перевіряє результат.

## Технології

- JavaScript
- Node.js та npm
- Jest
- Git і GitHub
- GitHub Actions
- Visual Studio Code
- GitHub Copilot

## Структура репозиторію

- `.github/agents/` — маніфест AI-агента.
- `.github/prompts/` — інструкції для окремих операцій.
- `.github/skills/` — повторно використовувані навички агента.
- `.github/workflows/` — конфігурації автоматизації GitHub Actions.
- `src/` — вихідний код програми.
- `tests/` — модульні тести.
- `docs/` — архітектура та документація.

## Запуск AI-агента

1. Відкрити репозиторій у Visual Studio Code.
2. Відкрити Copilot Chat.
3. Вибрати спеціалізованого агента `build-engineer`.
4. Запустити потрібний сценарій через відповідний prompt або попросити агента виконати повний цикл автоматизації.
5. Перевірити створені файли, результати складання та проходження тестів.

## Запуск програмного проєкту

Після створення JavaScript-проєкту та налаштування `package.json`:

```powershell
cd hello-world
npm install
npm run build
npm test
npm start
```

Назви команд повинні відповідати фактичним npm scripts, створеним у `package.json`.

## Перевірка CI/CD

Автоматична перевірка виконуватиметься через GitHub Actions. Workflow повинен запускати складання та тести на Windows, Linux і macOS.
